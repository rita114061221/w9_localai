01 • 認識輔助科技

本單元介紹高科技輔具的種類、用途與技術原理，並說明輔具如何改善使用者生活，搭配實際案例分享。

📚 什麼是輔助科技（Assistive Technology, AT）

輔助科技是指任何用來維持、增加或改善殘障者或高齡者功能的裝置、設備、軟體或系統。高科技輔具通常包含電子元件、感測器與程式控制，能夠提供更精準、更即時的協助。

輔具與一般工具的差異 ▶

一般工具是供大眾使用，而輔具是針對特定身體功能限制所設計，目的是協助使用者完成日常生活活動（ADL），例如行動、進食、穿衣、溝通等。

📕 高科技輔具種類與用途

輔具類別常見範例主要用途
行動輔具智慧手杖、電動輪椅、外骨骼協助行走、移動與平衡
協助握持輔具電動夾持器、自助餐具協助抓握物品與進食
溝通輔具視線輸入板、語音合成器協助無法說話者表達意願
感官輔具助聽器、電子放大鏡、盲文顯示器補償視聽障礙

📐 技術原理概述

高科技輔具通常由四大模組組成：

📅
感測模組

偵測環境與使用者訊號（按鈕、肌電、光線、距離等）。

🔎
控制模組

處理輸入訊號並做出決策（Arduino、ESP32 等微控制器）。

🔐
驅動模組

執行物理動作（馬達、伺服器、電磁閥等）。

💻
能源模組

提供電力供應（電池、電源管理電路）。

02 • 科技原理教室

本單元詳細教學感測器、Arduino 微控制器、馬達與致動器、控制系統分析以及基礎程式設計，適合初學者從頭開始學習。

📅 常見感測器與工作原理

感測器將物理量轉換為電訊號，讓微控制器能夠讀取環境或使用者狀態。

感測器偵測對象輸出訊號輔具應用範例
按鈕 / 開關使用者按壓數位 (0/1)啟動/停止輔具動作
超音波感測器前方距離類比 / PWM避障與距離警示
肌電感測器 (EMG)肌肉收縮訊號類比電壓義肢控制、握持觸發
光敏電阻環境光強度類比電阻自動開關燈光

📖 讀取類比感測器範例

int sensorPin = A0;
int sensorValue = 0;
float voltage = 0;

void setup() {
  Serial.begin(9600);
  pinMode(sensorPin, INPUT);
}

void loop() {
  sensorValue = analogRead(sensorPin);
  voltage = sensorValue * (5.0 / 1023.0);
  Serial.print("值=");
  Serial.print(sensorValue);
  Serial.print(" 電壓=");
  Serial.println(voltage);
  delay(200);
}

原理說明： Arduino Uno 的類比輸入為 10 位元，0~1023 對應 0~5V。公式：電壓 = 數值 × (5.0 / 1023.0)。

📗 Arduino 與微控制器基礎

Arduino 是開源電子原型平台，包含硬體開發板與 Arduino IDE 軟體。它是許多高科技輔具的控制核心。

📖 伺服馬達控制範例

#include 
Servo myServo;

void setup() {
  myServo.attach(9);  // 連接至 D9 腳位
  myServo.write(0);   // 初始角度 0 度
}

void loop() {
  myServo.write(90);  // 轉到 90 度
  delay(1000);
  myServo.write(0);   // 回到 0 度
  delay(1000);
}

📑 控制系統方塊圖分析

開迴路控制：輸入直接對應輸出，不回饋狀態。閉迴路控制：透過感測器回饋，根據誤差修正輸出，較為穩定。

💻 基礎程式設計概念

  • 變數：儲存感測器數值或系統狀態。
  • 條件判斷 (if)：根據感測值決定輔具動作。
  • 迴圈 (for/while)：重複執行動作或持續偵測。
  • 函數：將常用程式封裝，方便重複呼叫。

📖 感測器觸發馬達範例

int sensorPin = A0;
int servoPin = 9;
int threshold = 500;

#include 
Servo myServo;

void setup() {
  Serial.begin(9600);
  pinMode(sensorPin, INPUT);
  myServo.attach(servoPin);
  myServo.write(0);
}

void loop() {
  int value = analogRead(sensorPin);
  Serial.println(value);

  if (value > threshold) {
    myServo.write(90);   // 輔具啟動
  } else {
    myServo.write(0);    // 輔具停止
  }
  delay(100);
}

📕 智慧手杖製作說明

智慧手杖利用超音波感測器偵測前方障礙物，當距離過近時透過蜂鳴器與震動馬達提醒使用者。

int trigPin = 7;
int echoPin = 6;
int buzzerPin = 8;
int ledPin = 13;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  float distance = duration * 0.034 / 2;

  Serial.print("距離: ");
  Serial.print(distance);
  Serial.println(" cm");

  if (distance > 0 && distance < 50) {
    tone(buzzerPin, 1000);
    digitalWrite(ledPin, HIGH);
  } else {
    noTone(buzzerPin);
    digitalWrite(ledPin, LOW);
  }
  delay(200);
}

💽 輔助機械手製作說明

輔助機械手透過伺服馬達控制手指彎曲與伸直，協助肌力不足者握持物品。

#include 
Servo thumbServo;
Servo indexServo;
int sensorPin = A0;
int threshold = 600;

void setup() {
  Serial.begin(9600);
  thumbServo.attach(9);
  indexServo.attach(10);
  pinMode(sensorPin, INPUT);
  openHand();
}

void loop() {
  int value = analogRead(sensorPin);
  Serial.println(value);

  if (value > threshold) {
    closeHand();  // 偵測到肌肉訊號，握持
  } else {
    openHand();   // 釋放
  }
  delay(150);
}

void openHand() {
  thumbServo.write(0);
  indexServo.write(0);
}

void closeHand() {
  thumbServo.write(90);
  indexServo.write(90);
}
